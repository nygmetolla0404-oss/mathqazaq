# mathqazaq

**QAZAQ MATH: Қазақстанды математикамен танимыз** — 1–11 сынып оқушыларына арналған 3D интерактивті математикалық платформа.

Автор: **Тэтбенова Әсем Данатарқызы**, математика пәнінің мұғалімі, «Қарақұм жалпы білім беретін мектебі» КММ.

## Мүмкіндіктер
- Қазақстанның 3D картасы: атпен шабу, бүркітпен ұшу, қалықтау; жылдамдық, биіктік, жол, уақыт, азимут
- 18 портал-әлем: 54 есеп → 3D «формула кітабы», 18 симулятор, 18 бейне-трейлер, сызғыш пен транспортир
- «Адал азамат» — функционалдық сауаттылық зертханалары (теңге, таразы, сағат, энергия, тежеу жолы)
- Математикалық зертхана (асық, бәліш, арқан тартыс, киіз үй…)
- Оқушы логині/құпиясөзі, QR арқылы кіру, мұғалім кабинеті (онлайн сынып, статистика, логиндер)
- Қазақша аудиогид (нейрондық дауыс, акцентсіз)

## Іске қосу
- **Интернетте:** GitHub Pages сілтемесі арқылы ашылады (бір құрылғы режимі).
- **Сыныпта (бүкіл сынып бір картада):** мұғалім компьютерінде `python3 server.py` → оқушылар экрандағы QR-кодты сканерлейді.

Толық нұсқаулық — `ІСКЕ_ҚОСУ.txt`.

## Құрылымы
`app.html` — платформа беті (claude.ai нұсқасы), `index.html` — `tools/build_index.py` арқылы жасалатын толық HTML, `js/` — 3D қозғалтқыш, симуляторлар, кітаптар, трейлерлер, `audio/` — қазақша дыбыс, `server.py` — сынып сервері.
